## 技術情報

### HTML データ構造

```javascript
// 各商品オブジェクト（例）
{
  id: 1,
  name: '季節のプレートごはん',
  priceJPY: 2100,          // 日本円価格
  category: 'カフェ',       // 固定：Phase 1は全てカフェ
  subcategory: 'ごはん',    // セクション（UI表示用）
  icon: '🍱',              // emoji icon
  type: undefined,         // 'ICE', 'HOT', 'ICE/HOT' または未設定
  soldOut: false,          // 売切状態
  veg: true,              // 菜食対応フラグ
  description: '自家製塩麹からあげ...'  // 説明文（オプション）
}
```

### Uii 換算ロジック

- **計算式**: `Uii = 円価格 × 0.8`（20%割引相当）
- **例**: 2,100円 → 1,680 Uii
- **実装**: `toUii()` メソッド（HTMLモック Alpine.js）

## Phase 1 制約・制限

### 注文可能条件（v13 §5.4）

- ✅ **チェックイン中のユーザー**: 全メニュー注文可
- ❌ **未チェックイン**: 商品に「🔒 要チェックイン」表示、カート投入禁止
- ❌ **代理注文**: 対象も「現在チェックイン中のユーザー」のみ

### SOLDOUT 管理

- 店員タブレットから即座に ON/OFF 可能（トグルスイッチ）
- 売切時は客スマホ画面に **即時反映**（リアルタイム同期）
- 売切商品のカート投入はブロック

### 会計処理

- 注文は「**未会計**」として伝票計上
- チェックアウト時に一括精算（QRコード決済）
- 伝票の修正・取消は管理画面から対応可能（誤入力補正）
