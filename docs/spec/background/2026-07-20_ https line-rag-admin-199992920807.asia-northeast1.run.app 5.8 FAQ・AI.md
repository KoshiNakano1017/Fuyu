### 🧑 User

https://line-rag-admin-199992920807.asia-northeast1.run.app/ 5.8 FAQ・AIコンシェルジュ機能（RAG）について LINEとGeminiのチャットBOTを作成した 添付の要件定義とURLを読み込んで内容を要約

### 🤖 Gemini

要件定義書（特に「5.8 FAQ・AIコンシェルジュ機能（RAG）」の記述）および提示された管理画面URL（LINE RAG Admin）の構成に基づき、 **FAQ・AIコンシェルジュ機能（RAG）の概要とシステム仕様** を以下のように要約・整理しました。

* * *

##### **1\. 機能の目的と概要**

*

### 🤖 目的

運営側の問い合わせ対応コスト削減と、利用者の情報アクセス性向上。
*

### 🤖 仕組み

LINE Messaging APIをフロントエンドとし、LLM（Gemini等）およびRAG（検索拡張生成）技術を組み合わせたAIコンシェルジュ（Bot）を構築。
*

### 🤖 特徴

単なる定型文返信ではなく、コミュニティの最新ナレッジ（FAQ・ガイドライン・ルール・ナレッジベース等）をデータベース化・ベクトル化し、問い合わせ内容に合わせた的確な回答を自然言語で自動生成します。

* * *

##### **2\. 主要機能とシステム構成（管理画面・RAG連携機能）**

提供された管理機能（line-rag-admin）および設計書に基づく主要モジュールは以下の通りです。

###### **① ドキュメント・ナレッジ管理（RAG基盤）**

*

### 🤖 ナレッジ登録・更新

施設利用ルール、クエストの仕様、Uii（地域通貨）の使い方、生活ガイドなどを管理画面から登録・一括管理。
*

### 🤖 ベクトル検索（pgvector等）

登録された文書データをチャンク分割・ベクトル化し、ユーザーからの質問に対して関連度の高い情報を高速抽出。

###### **② ユーザー属性に応じたコンテキスト切り替え**

*

### 🤖 属性判定（メンバー vs ゲスト）

*

### 🤖 一般会員（長期滞在者）

業務手順、ツール使い方、高度な運営ルールなどを案内。
    *

### 🤖 ゲスト（短期滞在者）

施設案内、チェックイン/アウト、基本的なコミュニティルールをわかりやすく案内。
*   ユーザーの権限や属性フラグに連動して回答の解像度やプロンプト（指示文）を動的に調整。

###### **③ 自動応答・エスカレーション管理**

*

### 🤖 一次受け対応

AIがRAG検索結果を基に一次回答を即座に生成。
*

### 🤖 エスカレーション基準（未決・不明回答時）

AIでの回答困難・ハルシネーションリスクがある内容や、運営による個別の判断が必要な問い合わせについては、人間の運営管理者へ通知（エスカレーション）する運用フローを構築。

###### **④ プロンプト・ログ管理（運用改善）**

*

### 🤖 対話ログの蓄積

会話履歴（AI\_CHAT\_LOG）を保存し、頻出する質問や不適切な回答ログを可視化。
*

### 🤖 FAQの継続的ブラッシュアップ

未回答・誤回答のデータを基にナレッジベースおよびシステムプロンプトのチューニングを実施。

* * *

##### **3\. 技術スタック・インフラ位置づけ**

*

### 🤖 フロント（対話インターフェース）

LINE Messaging API
*

### 🤖 AI・LLMエンジン

Gemini API / Claude API（RAGパイプライン・Agent）
*

### 🤖 バックエンド・DB

Cloud Run（管理画面・APIホスティング）、Supabase PostgreSQL（pgvectorによるベクトル検索）
*

### 🤖 外部連携拡張性

将来的にはMCP（Model Context Protocol）等を介して、場所づくりナレッジ（FEL）や各種マスタデータとも連携可能な柔軟性を保持。

* * *

##### **まとめ**

今回の構成は、\*\*「LINEを通じた手軽なUI」 **と** 「管理画面を通じたRAG用ナレッジデータベースの運用管理」\*\*を直結させることで、浮遊街における日常の問い合わせを自動処理し、ユーザー属性に合わせた最適な案内をリアルタイムに提供するAIコンシェルジュ基盤となっています。

### 🧑 User

登録するナレッジの例

### 🤖 Gemini

管理画面（RAG Admin）のナレッジデータベース（ベクトル検索基盤）に登録すべき **具体的なナレッジ（データ項目・Q&Aドキュメント）の例** を、ユーザー属性および機能カテゴリ別に整理しました。

* * *

##### **1\. ゲスト（短期滞在者）向けナレッジ**

初めて滞在するゲストや短期滞在者がLINE BOTに質問した際、的確に自動応答するための基礎情報です。

*   **施設利用・宿泊規約**
    *   チェックイン／チェックアウトの時間と場所、鍵の受け渡し方法
    *   ゴミの分別ルール、夜間の静音ルール、共有スペース（キッチン・コワーキングなど）の利用規約
    *   Wi-Fiパスワード、備品（ドライヤー、洗濯機など）の利用手順
*   **基本システム・ルール**
    *   浮遊街の理念（腐る経済、地域通貨「Uii」の概念）の説明
    *   ゲストが参加可能な体験型クエストの一覧と参加方法
    *   困ったときの運営スタッフ連絡先・緊急連絡フロー

* * *

##### **2\. 一般会員（長期滞在者・コアメンバー）向けナレッジ**

業務手順やコミュニティ運営に関わる、より高度で解像度の高いマニュアルや仕様です。

*   **クエスト・業務運用**
    *   クエストの新規作成・登録ルール（想定工数の算出方法、付与XP・Uiiの基準）
    *   クエスト完了報告の作成フォーマットと承認申請の手順
    *   スキルレベル（Lv1〜5）の昇格要件と「推薦」手順
*   **Uii（地域通貨）運用**
    *   Uiiのチャージ・送金・決済の手順（eumoアプリ連携等）
    *   Uiiの減価（腐るルール）および残高の確認・管理手順
*   **施設・設備メンテナンス（場所づくり）**
    *   工具や農機具の管理方法・保管場所・安全確認チェックリスト
    *   季節ごとのタスク（草刈り、薪割り、農作業等）の作業マニュアルと注意点

* * *

##### **3\. 運営・管理（エスカレーション・AI制御）用ナレッジ**

AI（Gemini/Claude）が回答を生成する際の境界線（ポリシー）を制御するためのガイドラインです。

*   **自動応答・エスカレーション基準**
    *

### 🤖 即時エスカレーション対象

事故・トラブル・怪我、お金（Uii）の不整合・不正、設備破損
    *

### 🤖 回答不可対象

個人情報開示、個別決済の可否判断などの運営判断を伴う内容
*   **プロンプト用ポリシー・振る舞い定義**
    *   ゲストと会員で回答の解像度を変える条件判定ルール
    *   ハルシネーション防止のための「不明な場合は無理に答えず運営に繋ぐ」応答テンプレート

* * *

##### **【ナレッジ登録時のテキスト例（テキスト形式／Q&A形式）】**

ベクトル検索（RAG）の検索精度を高めるため、以下のような形式で小分け（チャンク化）して管理画面に登録します。

###### 例1：Q&A形式（施設・ルール）

**\[タイトル\]** Wi-Fiの接続方法について **\[対象属性\]** ゲスト / 一般会員 **\[本文\]** > Q: 施設内でWi-Fiは使えますか？パスワードを教えてください。 A: メイン棟および宿泊スペースにて「FloatingCity\_Guest」のSSIDがご利用いただけます。パスワードは xxxxxxxx です。通信速度が低下した場合は、ルーターの再起動を行わず運営チャットまでご連絡ください。

###### 例2：マニュアル・手順形式（クエスト運用）

**\[タイトル\]** クエスト完了報告とUii付与の承認フロー **\[対象属性\]** 一般会員 **\[本文\]** クエストが完了したら、アプリの「完了報告」画面から写真と作業時間を提出してください。提出後、査定員（コミュニティリーダー）による確認が行われ、承認されると自動的にXPおよび地域通貨Uiiが付与されます。24時間以上承認されない場合は、LINE Botから「クエスト承認の確認」と発言することで進捗状況を確認できます。

###### **1\. 施設利用ルール（ゲスト・一般会員共通）**

*

### 🤖 想定質問

浮遊街のチェックインやチェックアウトの時間を教えてください。鍵はどこで受け取りますか？
*

### 🤖 回答

チェックインは15:00〜18:00、チェックアウトは10:00までです。到着されましたら、メイン棟の受付デスクにあるスマートロックまたは管理窓口にて鍵をお受け取りください。遅れる場合は事前にLINEでご連絡をお願いします。
*

### 🤖 カテゴリ

施設・宿泊規約
*

### 🤖 ソース

浮遊街アプリ 滞在管理マニュアル v1.0

###### **2\. 共有スペース規約（ゲスト・一般会員共通）**

*

### 🤖 想定質問

共有キッチンやコワーキングスペースは夜間何時まで使えますか？
*

### 🤖 回答

共有スペースは24時間利用可能ですが、近隣や他の滞在者への配慮のため、22:00〜翌朝7:00までは消音時間（クワイエットタイム）となっています。大声での会話や宴会、大きな音の出る作業はお控えください。
*

###### **3\. 地域通貨Uiiの基礎（ゲスト向け）**

*

### 🤖 想定質問

地域通貨「Uii（ウイ）」とは何ですか？日本円は使えますか？
*

### 🤖 回答

「Uii」は浮遊街の中だけで流通する独自の地域通貨です。日本円などの既存通貨を使わず、「腐る経済（溜め込まずに循環させる）」をコンセプトとしています。クエストを達成することで獲得でき、街の中での食事やサービス利用に使えます。
*

### 🤖 カテゴリ

Uii・コミュニティ理念
*

### 🤖 ソース

浮遊街AI\_構築ロードマップ\_v6.pdf

###### **4\. クエストの受諾・参加方法（ゲスト・一般会員共通）**

*

### 🤖 想定質問

街の中での仕事（クエスト）にはどうやって参加できますか？
*

### 🤖 回答

アプリの「クエスト一覧」から、現在募集中のクエスト（畑仕事、DIY修繕、調理補助など）を確認して「参加する」ボタンを押してください。自分のスキルレベルに合わせた作業を選ぶことができます。
*

### 🤖 カテゴリ

クエスト・業務運用
*

浮遊街クエストアプリ要求仕様書

###### **5\. クエスト完了報告フロー（一般会員向け）**

*

### 🤖 想定質問

クエストが終わったら、どうやって完了報告をして報酬（Uii）をもらえばいいですか？
*

### 🤖 回答

クエスト完了後、アプリの報告画面から「作業内容の写真」と「実施時間」を記入して送信してください。査定員（コミュニティリーダー）の承認後、自動的にXP（経験値）とUiiが付与されます。
*

### 🤖 カテゴリ

###### **6\. スキルレベルと昇格要件（一般会員向け）**

*

### 🤖 想定質問

スキルレベル（Lv.1〜5）を上げるにはどうすればいいですか？
*

### 🤖 回答

該当スキルのクエストを複数回こなしてXP（経験値）を溜めることでレベルアップします。なお、Lv.4以上の高級職や専門レベルに昇格するには、他のメンバーからの「推薦」や指定のイベント企画などの実績が必要となります。
*

###### **7\. eumo（ユーモ）送金の手順（一般会員向け）**

*

### 🤖 想定質問

クエストで稼いだUiiをeumoアプリで送金・利用する手順を教えてください。
*

### 🤖 回答

アプリ内のマイページから「eumoで受け取る/送金する」を選択し、表示されたリンクからeumoアプリを立ち上げてください。決済完了後、浮遊街アプリに戻り「完了報告」を行うことで帳簿側へ自動反映されます。
*

### 🤖 カテゴリ

*

###### **8\. 機材・工具の管理と安全基準（一般会員向け）**

*

### 🤖 想定質問

共有の農機具やDIY工具（草刈り機や電動ドリル）を使用する際のルールはありますか？
*

### 🤖 回答

工具倉庫のチェックリストに従い、使用前点検と使用後の清掃を行ってください。草刈り機等の危険を伴う機材は、該当スキルLv.2以上のメンバーと同伴または安全講習を受けた上でご利用ください。破損や不具合があった場合は速やかに運営へ連絡してください。
*

###### **9\. 未解決問い合わせのエスカレーション（AI応答ポリシー）**

*

### 🤖 想定質問

AIで回答できないトラブル（怪我、事故、設備の破損、お金の計算ミス）が起きたらどうなりますか？

事故・トラブル・怪我・決済不整合などの緊急性の高い案件や個別の判断が必要な内容については、AIが「運営スタッフへエスカレーションを行います」と案内し、運営管理者のLINE/通知ツールへダイレクトにアラートを送信します。

###### **10\. ゲストと一般会員での情報案内切り替え（AI応答ポリシー）**

*

### 🤖 想定質問

ゲストと一般会員でAIの回答内容が変わることはありますか？

### 🤖 回答

はい。AIコンシェルジュはユーザーの属性フラグ（ゲストか一般会員か）を判別しています。ゲストには施設案内や簡単な体験クエストを中心に分かりやすく案内し、一般会員には業務マニュアルや高度なルール設定を含む解像度の高い情報を案内します。
