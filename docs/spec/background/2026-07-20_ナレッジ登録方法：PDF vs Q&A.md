# ナレッジ登録方法：PDF vs Q&A

### 🧑 User

ナレッジの登録方法どうしよう PDFやMDを読ませるか、自分で質問と回答を設定するjか

### 🤖 Gemini

RAG（検索拡張生成）を用いたAIコンシェルジュ／チャットボットシステムにおいて、ナレッジの登録方法を「ドキュメント（PDF/Markdown等）をそのまま読み込ませる方式」にするか、「Q&A形式（一問一答）で自作して登録する方式」にするかは、 **運用コストと検索・回答の精度（回答の質）のトレードオフ** によって決めるとスムーズです。 両方式のメリット・デメリットと比較、およびおすすめのハイブリッド運用案をご提案します。

* * *

##### 1\. ドキュメント（PDF / MD）をそのまま読み込ませる方式

既存のマニュアル、ガイドライン、ルールブック等のファイルを直接登録・ベクトル化する方式です。

*   **メリット**
    *

### 🤖 準備の手間が非常に少ない

すでにある資料やマニュアルをアップロードするだけで即座に運用可能です。
    *

### 🤖 網羅性が高い

Q&Aとして抽出していなかった細かい注意点や背景知識もAIが検索対象として参照できます。
*   **デメリット**
    *

### 🤖 検索ミスのリスク

PDFのレイアウト（表組み、画像内のテキスト、複雑なヘッダー・フッターなど）によって文章の繋がりが崩れ、正しくベクトル検索できない場合があります。
    *

### 🤖 回答が曖昧になる可能性

質問文とドキュメント内の表現（表記揺れや文脈のズレ）によって、意図した箇所のドキュメントがヒットしないことがあります。

* * *

##### 2\. Q&A形式（質問と回答の対）を設定する方式

ユーザーから想定される質問と、それに対する正確な回答をペア（構造化データ）にして登録する方式です。

*   **メリット**
    *

### 🤖 回答精度が大幅に高くなる

ユーザーの質問（「〜はどうすればいい？」）とナレッジの質問文が直接マッチするため、RAGでのヒット率が格段に上がります。
    *

### 🤖 ピンポイントで正確な返答ができる

不要な情報が混ざらず、短く的確な回答を生成・提供させやすくなります。
*   **デメリット**
    *

### 🤖 作成コストがかかる

マニュアルからQ&Aを1つずつ抽出して作成する時間とコストがかかります。

* * *

##### 比較まとめ

比較項目

ドキュメント（PDF/MD）直接読み込み

Q&A（質問・回答対）手動・構造化登録

**準備・登録コスト**

非常に低い（ファイルを入れるだけ）

やや高い（Q&A作成が必要）

**回答の精度・確実性**

中（文脈やレイアウトに左右される）

**非常に高い** （ピンポイントでヒット）

**複雑・長文ルールへの対応**

**得意** （全体構造から要約・整理可能）

やや不向き（Q&Aが膨大になりがち）

**運用のしやすさ**

マニュアル更新時に差替のみ

定期的なFAQの見直し・追加が必要

* * *

##### 💡 推奨する進め方（段階的ハイブリッドアプローチ）

最初からどちらか一方に絞るのではなく、以下のステップで進めるのが最も効率的でおすすめです。

1.  **フェーズ1：PDF / Markdown をベースとして一括登録する**
    *   既存のマニュアルやガイドライン等のドキュメント（MDまたはテキスト整形済みのPDF）をそのままナレッジベースに投入し、即座にチャットボットを運用開始できるようにします。
2.  **フェーズ2：AIを活用してPDF/MDから「Q&Aリスト」を自動生成する**
    *   マニュアルのテキストをGeminiなどのLLMに入力し、「このマニュアルから想定されるユーザーの質問と回答のペア（Q&A）をMarkdown/JSON形式で20件抽出してください」と指示してQ&Aを作成させます。
    *   これにより、手動でQ&Aを作る手間を大幅に削減できます。
3.  **フェーズ3：頻出問い合わせ・重要項目のみ「Q&Aデータ」として優先登録する**
    *   利用頻度が高い内容（例：草刈機の使い方、eumoの送金・連携、施設・宿泊案内、完了報告手順など）は、個別のQ&Aとして登録しておくことで、誤回答を防ぎ高精度な自動応答を実現します。 ご希望であれば、手元にある資料やマニュアルテキストをこちらに送っていただければ、チャットボットのRAGに最適化した「Q&A形式のナレッジデータ」に整形・変換・整理することも可能です。

###### Q1: コミュニティ通貨「Uii（ユーモ/DANROコイン）」とは何ですか？

```text
【質問】
コミュニティ通貨「Uii」とは何ですか？どのような特徴がありますか？

【回答】
Uii（ユーモ/DANROコイン）は、浮遊街（1,000人で創造するコミュニティ）内で流通する独自のコミュニティ通貨です。
日本円や一般的な通貨とは異なり、「腐る経済（有効期限あり）」の仕組みを取り入れています。貯め込むのではなく、街の中で循環・応援・感謝の対価として巡らせることで、みんなで「やりたいことで生きられる街」を共創することを目的としています。

```

###### Q2: Uiiの「貯め方（稼ぎ方）」を教えてください。

```text
【質問】
Uii（地域通貨）はどうやって貯める（稼ぐ）ことができますか？

【回答】
Uiiは主に以下の方法で得ることができます。
1. クエストへの参加・貢献：草刈り、農作業、DIY、イベント設営、広報、案内などの街づくりクエストを完了し、査定員の承認を受けると報酬として付与されます。
2. 小商いやスキルの提供：マッサージ、野菜の販売、手作りスイーツやワークショップ、スキル提供などの対価として他のメンバーから受け取ることができます。
3. 仲間からの感謝・応援（ギフト/推薦）：他のメンバーから感謝の気持ちや推薦として贈られることがあります。

```

###### Q3: Uiiの「使い方（消費方法）」を教えてください。

```text
【質問】
獲得したUiiはどこで・何に使えますか？

【回答】
Uiiは浮遊街内および関連加盟店で以下のように使用できます。
1. 拠点・カフェ・BARでの決済：浮遊街の心臓部であるカフェ・BARスポット（Mol Cafe等）での飲食代の支払いに使用できます。
2. 小商い・メンバー間取引：他の街人が出品している野菜の購入、施術（マッサージ等）、クラフト作品の購入やサービスの対価として送金・使用できます。
3. クエストの発注・応援：自分が依頼したい作業の報酬として提示したり、応援したいメンバーへ送金・ギフトすることができます。

```

###### Q4: Uiiの有効期限（腐る経済）について教えてください。

```text
【質問】
Uiiに有効期限はありますか？使わないとどうなりますか？

【回答】
はい、Uiiには「3ヶ月」の有効期限が設定されています（腐る経済の仕組み）。
期限が切れたコインは消滅するか、コミュニティの共有財産（プール）に還流されます。そのため、貯め込まずに積極的に使ったり、他の仲間を応援・循環させることが推奨されています。

```

###### 【カテゴリ：アプリでの設定・操作方法】

###### Q5: アプリでUii残高や履歴を確認する方法を教えてください。

```text
【質問】
アプリでUiiの残高や使った履歴（何に払ったか）を確認するにはどうすればいいですか？

【回答】
浮遊街アプリの「マイページ」からご確認いただけます。
1. アプリ内の「マイページ」または「ウォレット」メニューを開きます。
2. 現在の「Uii所持残高」と「有効期限」が表示されます。
3. 「取引履歴」から、クエスト報酬で獲得した履歴や、カフェ・小商いで何（マッサージや野菜など）に消費したかのメタデータ（利用内訳）を一覧で確認できます。

```

###### Q6: アプリからeumo（ユーモ）で送金・決済する手順を教えてください。

```text
【質問】
アプリからUiiを相手に送金したり、eumoで受け取る手順を教えてください。

【回答】
以下のステップで送金・決済を行ってください。
1. アプリのマイページまたは店舗/小商い画面から「eumoで送金する / 受け取る」を選択します。
2. 表示されたリンクまたはQRコードから「eumoアプリ」を立ち上げます。
3. eumoアプリ上で送金金額と利用目的（例：カフェ利用、野菜購入等）を入力して決済を実行します。
4. 決済完了後、浮遊街アプリに戻り「完了報告」を行うことで、アプリ内の帳簿・履歴へ自動反映されます。

```

###### Q7: クエストを完了してUiiを受け取る設定・申請手順を教えてください。

```text
【質問】
クエストが終わった後、どうやってアプリで報告してUiiを受け取りますか？

【回答】
クエスト完了時の報酬受け取り手順は以下の通りです。
1. 浮遊街アプリの「クエスト一覧」から、実施したクエストを選択します。
2. 「完了報告」ボタンをタップし、作業内容の写真と実施時間を入力して送信します。
3. コミュニティリーダー（査定員）の承認が完了すると、自動的にあなたのウォレットへUiiおよびXP（経験値）が付与されます。

```

クエストを受注しようとしたら「スキルレベルが足りません」と表示されました。なぜですか？
*

### 🤖 回答

一部の難易度が高いクエスト（熟練が必要な農作業、機材のメンテ、建築修繕など）には「推奨スキルレベル（例：農業Lv.2以上など）」が設定されています。 対象のスキルレベルが不足している場合は直接受注できません。まずはスキル制限のない初心者向けクエスト（Lv.1〜）を複数回クリアしてXP（経験値）を貯めるか、該当スキルを持つ先輩メンバーとペアを組んで参加（アシスタント参加）してください。
*

###### 10\. 現地に行けない場合のクエスト受注（遠隔クエスト）

*

### 🤖 想定質問

現地（浮遊街）に行けない期間でも受注できるクエストはありますか？（遠隔参加）
*

### 🤖 回答

はい、現地に行けないメンバー（通い型メンバー）向けに「遠隔クエスト」が用意されています。
    1.  クエスト一覧の検索フィルターで「遠隔可能」または「オンライン」を選択します。
    2.  SNS広報、イベントの資料整理、オンラインメンター、データ入力などの作業を受注できます。
    3.  作業完了後、アプリから成果物（テキストやURL、画像）を提出することで、現地参加と同様にUiiとXPを獲得できます。

###### 11\. 受注したクエストのキャンセル・変更

*

### 🤖 想定質問

受注したクエストを取り消したい（キャンセルしたい）場合はどうすればいいですか？
*

### 🤖 回答

実施前であればアプリからキャンセルが可能です。
    1.  アプリのマイページにある「参加中クエスト」を開きます。
    2.  対象のクエストを選択し、「受注をキャンセルする」をタップしてください。 ※直前のキャンセルや無断での取り消しは、他のメンバーの作業準備に影響が出ますので、予定が変わった場合はできるだけ早めにキャンセル処理を行うか、チャット機能でコミュニティリーダーへご連絡ください。

###### 12\. ゲスト（短期滞在者）のクエスト受注制限

*

### 🤖 想定質問

ゲスト（非会員・短期滞在者）でもクエストを受注できますか？
*

### 🤖 回答

ゲスト権限の場合、受注できるクエストに一部制限が設けられています。 ゲスト向けに開放されている「体験型クエスト（初心者向けの畑作業、イベントのお手伝いなど）」のみ受注が可能です。より多くの種類のクエストや、専門的な作業を受注したい場合は、会員権限（メンバー登録）への変更・昇格が必要となります。
*
