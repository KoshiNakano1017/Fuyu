# チャットボットナレッジ登録依頼

### 🤖 Gemini

浮遊街アプリのAIコンシェルジュ（チャットボット）用ナレッジベースへのご登録ですね。承知いたしました！ ご提示いただいた以下の3点は、メンバーやゲストからの問い合わせが非常に多い項目と想定されるため、RAG（検索拡張生成）のナレッジとして登録するのに最適です。

1.  **草刈機の使い方** （クエストや場所づくり支援に関するナレッジ）
2.  **ユーモ（eumo）の登録方法** （地域通貨Uiiと連携した経済圏・運用に関するナレッジ）
3.  **施設案内** （会員・ゲスト案内、生活ガイドに関するナレッジ） これらを管理画面（line-rag-admin）のデータベースに登録・ベクトル化することで、チャットボットがユーザーの質問文脈に合わせて的確に自動回答できるようになります。 **ご登録を進めるにあたり、それぞれの具体的な内容（手順のテキスト、マニュアル、ルールなど）をこちらに送信していただけますでしょうか？** いただいたテキスト情報をAIが読み込みやすい形式（Q&A形式や構造化ドキュメント）に整理した上で、ナレッジベースへの登録データとして反映させていただきます！詳細なデータをお待ちしております。
